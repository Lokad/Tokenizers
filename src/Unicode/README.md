# Unicode 15.1 profile

`Unicode15_1.bin` is generated by `eng/generate-unicode.py` from the official [Unicode 15.1 UCD archive](https://www.unicode.org/Public/zipped/15.1.0/UCD.zip). Its SHA-256 is pinned in the generator: `cb1c663d053926500cd501229736045752713a066bd75802098598b7a7056177`. `LICENSE.txt` carries the Unicode data license and is included in the NuGet package.

The compact little-endian resource contains character-property ranges, canonical combining classes, normalization quick-check ranges, default context-free lowercase mappings, recursive decompositions and allowed canonical compositions. Hangul decomposition/composition follows the algorithm in [UAX #15 revision 54](https://www.unicode.org/reports/tr15/tr15-54.html). Unassigned and noncharacter scalars pass through normalization unchanged. Invalid UTF-16 fails explicitly. Lowercasing is scalar-based (including the unconditional dotted-I expansion), preserving the legacy treatment of Greek sigma rather than applying whole-string context rules. CJK token splitting retains its documented fixed ranges.

Normalization preserves per-scalar origins through decomposition, stable canonical ordering and composition. Disordered nonstarter runs are sorted in O(n log n), avoiding quadratic insertion behavior on long combining sequences. Public template results own copies of their mutable metadata.

The official `NormalizationTest.txt` is stored compressed under `test/Unicode/`. Its decompressed SHA-256 is `871238e37e3be0696ec2bd0891119a041b052da1a84485eda05a5438724b223e`; all normative five-column relationships are exercised offline. Generation checks compare decompressed corpus bytes so zlib version differences cannot cause false failures.

`eng/test-unicode.ps1` independently checks every scalar's casing, properties and four normalization forms against Python 3.13 / Unicode 15.1. Python's Unicode implementation does not consume this resource or generated tables. CI runs both generation and exhaustive profile checks; the library's Unicode processing does not use Python or host ICU data.
